domma-celebrate

Eight celebrations that know their own place in the calendar. Pick one below, then switch individual traits off - the sleigh, the steam train, the witches - and watch the canvas reseed. Nothing on this page uses a framework.

off

What appears

One script tag

<script src="domma-celebrate.min.js" data-celebrate></script>

That is the whole integration. It works out whether anything is in season, draws it, and mounts a control disc so a visitor can turn it off - remembered for next time.

Or drive it yourself

import { Celebrations } from 'domma-celebrate';

const celebrations = new Celebrations({
  theme: 'christmas',
  intensity: 'medium',
  traits: { train: false, elf: false, tree: 0.5 }
});

await celebrations.init();
